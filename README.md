# Missing Value Identification

## Overview
This project identifies missing values in a dataset using Python, Pandas, and Excel.

## Objectives
- Identify missing values.
- Count missing values in each column.
- Calculate missing-value percentages.
- Summarize findings.
- Understand why blindly deleting rows can be risky.

## Dataset
Iris Flower Dataset – 150 records and 6 columns.

Note: 17 controlled missing values were introduced for demonstration purposes. The original Iris dataset is complete.

## Tools Used
- Python
- Pandas
- Excel

## Results
- Total records: 150
- Total columns: 6
- Total missing cells: 17
- Columns containing missing values: 5
- Rows containing missing values: 17

## Deliverables
1. Missing Value Identification Excel Workbook
2. Dataset CSV File
3. Short Findings Report

## Conclusion
Missing values were successfully identified and summarized. No rows or values were deleted. Appropriate treatment should be selected only after investigating the reason for missing data.
